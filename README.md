# mkcloud 独享带宽：5M–300M 全档位价格一览，含共享/独享核心差异对比

"独享带宽"这个词听起来很简单，但放到跨境专线 VPS 的语境里，它和一个数字绑在一起：这款套餐每月能持续跑多少 Mbps 的速度。与共享带宽"峰值"不同，独享带宽是你这台机器的稳定速率承诺，跑满就跑满，没有和别人抢。

Mkcloud 的独享带宽产品目前覆盖广东-香港 IEPL、上海-香港 IPLC、上海-日本 IPLC、上海-美国 IPLC、福建-香港 高防 IPLC，以及上云互联入口的几个方向。共享流量款上"独享"两个字后，计费方式从按月流量切成了按速率包月，入口、出口 IP、CPU/内存/硬盘这些基础资源保持独立。

这篇文章要解决的具体问题就一个：如果你已经在看 Mkcloud，想搞清楚独享带宽到底有几档、每档多少钱、和共享差在哪、自己这台业务到底要不要选独享——下面这些信息可以直接拿去下单或继续评估。

## 独享带宽到底在卖什么

独享带宽并不神秘。一句话概括：标称多少 Mbps，就能持续以这个速率跑出口，**没有月流量上限**（页面资料统一写成"无限制"），但在达到套餐速率上限后也不会自动提速。

Mkcloud 的独享带宽产品有几个共性：

- 每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP，独立 IPv4 两枚，绑定省份白名单（开通后可改）。
- 计费方式：带宽包月，不限流量。
- 端内延迟：广港 1–2ms，沪港 21ms，沪日 25–28ms，沪美 124–134ms。这是产品资料里给的端内参考数据，不等于"本地到任意目标网站"的完整延迟。
- CPU、内存、硬盘配置：5M/10M/20M 三档统一是 2 核 / 4GB / 40GB；50M 及以上档位统一是 4 核 / 8GB / 60GB。硬盘和算力是按带宽档位匹配的，不是按流量自定义。

需要看清的是，独享 ≠ 无限速。100M 独享套餐给出的就是 100Mbps 上限，超过部分不会继续叠加；只是没有设定月度流量封顶，连续上传 30 天也按同一个速率结算。

## 共享带宽和独享带宽差在哪

很多人分不清共享和独享的取舍。先把硬指标摊平：

| 维度 | 共享带宽（流量计费） | 独享带宽（带宽计费） |
| --- | --- | --- |
| 计费依据 | 月流量额度（GB / TB） | 持续速率（Mbps） |
| 标称带宽含义 | 峰值，不保证持续跑满 | 这台机器的稳定速率 |
| 月流量上限 | 有，超量后暂停 | 无限制（按速率结算） |
| 超量处理 | 自助购买流量重置或工单补差价升级 | 不存在超量问题 |
| 适合业务 | 间歇访问、短时突发传输 | 持续上传、长时间传输、固定速率需求 |
| 入门价格 | 广港 ¥358/月、沪港 ¥288/月（共享 1TB） | 广港 ¥500/月、沪港 ¥650/月（5M 独享） |

先把容易踩的坑说清楚：200Mbps 共享峰值不能直接和 5Mbps 独享比谁强。前者看的是"短时间能跑到多高"，后者看的是"长时间能稳定输出多少"。

如果业务是定期上传数据、推流、跨机器同步、或者要求带宽始终够用，独享型更适合。如果是偶尔登录后台、上传素材，共享流量款性价比更高。

## 独享带宽适合谁用

把上面这些档位换算成实际场景，可以更快判断自己需不需要：

**持续传输 / 跨机器同步**

如果业务是把数据从一个地方推到另一个地方，每小时都在用带宽，比 5M 独享是更稳妥的选择——共享款即便峰值再高，也无法保证一整小时跑到 100Mbps。

**固定码率推流 / 直播**

直播对带宽的要求集中在"稳定"。独享款标多少 Mbps，跑多少 Mbps，不存在和别的 VPS 抢带宽的情况。

**跨境店铺后台**

如果不是后台上传素材频繁，共享流量款就够了；如果每天有大文件上传和定时任务，独享 5M–10M 通常够用。

**测试线路本身**

下线前看哪条线对应端内延迟最低、最接近业务目标，再选低档位的独享（如 5M）做一段时间观察，比直接买大档位更稳。

**不适合独享带宽的场景**

只是登录后台、偶尔上传、或者用量集中在少数几天的高峰——共享流量款的月额度和峰值更适合这种不规律用量。

## 选购前必须确认的硬约束

独享款并不是开通即用。Mkcloud 的所有专线产品在订单层面有这些硬约束：

1. **省级白名单**：每台机器只允许一个省份的 IP 连入入口。开通后可以在工单里改为其他省份。
2. **实名要求**：所有专线产品需中国身份信息实名，仅限个人或企业正规用途。
3. **退款边界**：仅支持质量问题退款；服务开通后不支持更换到其他地域。退款需提交延迟、速度等具体证据。
4. **升降级规则**：升降级均需提交工单；降级到更低价格套餐时差价不退，是否迁移以工单处理结果为准。
5. **默认无 SLA**：标准产品默认没有 SLA 保证，明确的可用性或独享保障需要单独询价。

这些是产品页固定公示的条款，不是"售后解释"——选购前直接看到，省去后续来回沟通。

## 常见问题

**问：5M 独享够用吗？**

答：取决于业务。如果是日常后台 + 偶发上传，5M 够；如果是持续推送或备份同步，5M 是底线，但通常会建议 10M 起步。

**问：广港独享和沪港独享核心差别是什么？**

答：地理路径不一样。广港是腾讯广州八线 BGP 入口，端内 1–2ms，是站点最低延迟；沪港是 UCloud 上海 BGP 入口，端内 21ms。入口省份就决定了能从哪个省的 IP 连入。

**问：独享款可以月付吗？**

答：可以。专页上的默认计费就是月付；季付、年付等长周期价格随所选时段浮动，长周期报价要以下单页面为准。

**问：独享带宽有没有 SLA？**

答：标准产品默认无 SLA。需要明确可用性、独享保障或定制路由，需要单独询价。

**问：能否把共享款换成独享款？**

答：可以，需要提交工单；具体迁移进度以工单处理结果为准。降级到更低价格套餐时差价不退。

**问：退款怎么处理？**

答：仅质量问题退款。需提交工单，提供准确的具体延迟数据、速度数据以证明是产品服务质量问题。开通后不支持更换到其他地域。

**问：100M 独享和 1G 峰值共享，哪个适合我？**

答：100M 独享是这台机器的稳定 100Mbps 上限，流量不限；1G 峰值共享是"短时间能冲到 1Gbps"，但不能保证持续，且有月流量额度。持续传输选独享，间歇访问选共享。
